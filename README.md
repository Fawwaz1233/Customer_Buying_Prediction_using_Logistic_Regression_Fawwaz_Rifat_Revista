# Customer Buying Prediction using Logistic Regression

Proyek *machine learning* yang menerapkan **Regresi Logistik** untuk memprediksi kemungkinan pelanggan melakukan pembelian, berdasarkan data historis pelanggan.

## Isi Repository
- `P1G5_fawwaz_rifat.ipynb` — notebook eksplorasi data, pra-pemrosesan, pelatihan model regresi logistik, dan evaluasi.
- `P1G5_fawwaz_rifat_inference.ipynb` — notebook inference untuk prediksi pada data baru.
- `dataset_1.csv` — dataset pelanggan yang digunakan.

## Cara Menjalankan
1. Clone repository ini.
2. Buka `P1G5_fawwaz_rifat.ipynb` di Jupyter Notebook.
3. Jalankan seluruh sel secara berurutan untuk melihat proses pelatihan dan evaluasi model.
4. Gunakan `P1G5_fawwaz_rifat_inference.ipynb` untuk melakukan prediksi pada data baru.
